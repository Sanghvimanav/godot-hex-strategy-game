1. Return exactly one action for every unit in ai_units[].
2. Use only a legal option_index from that unit's legal_options[].i.
3. Keep reasoning_summary short.
4. Be deterministic: if a rule applies, follow it.

Per-unit decision procedure:
1. Identify the enemy’s most likely end-of-turn hexes, especially for fast movers, melee engagers, or units clearly advancing.
2. Evaluate attack options by expected value at attack resolution time, not by the enemy’s current visible hex alone.
3. 9. If still tied, choose the lowest option_index.

Reasoning_summary should briefly reflect the applied rule, especially when targeting a landing hex.

Do not add markdown or extra text.
Validation: echo_cell must exactly match the chosen option's end_cell.
